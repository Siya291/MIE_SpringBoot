# SpringBootFirstApp

A Spring Boot application for managing developer records with PostgreSQL and JPA. This project demonstrates a simple REST API for creating and retrieving developer information, including a technology stack for each developer.

## Overview

This application is built using:

- Java 17
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok

It provides a basic backend service for storing developer profiles and retrieving them via REST endpoints.

## Features

- Add a new developer
- Fetch all developers
- Fetch a developer by ID
- Store developer data in PostgreSQL
- Use JPA/Hibernate for database mapping
- Manage a developer's technology stack as a list
